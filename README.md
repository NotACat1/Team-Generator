# 🎮 Team Generator — Розыгрыш команд

Интерактивное Android-приложение, созданное с помощью **Jetpack Compose**, которое помогает быстро распределить игроков на две команды — 🔴 красную и 🟢 зелёную.  
Добавь участников, отметь присутствующих и нажми **«Сформировать команды»** — всё остальное сделает приложение!

---

## ✨ Основные возможности

- 👤 Добавление, редактирование и удаление игроков
- ✅ Отметка присутствующих для участия
- 🎲 Случайное распределение по командам
- 🧾 Просмотр результата с идентификаторами игроков
- 🧹 Очистка списка одним нажатием
- 💡 Полностью на **Jetpack Compose (Material 3)**

## 📂 Структура проекта

```

📦 com.example.lr4
┣ 📂 data
┃ ┗ 📜 Player.kt               # Модель игрока
┣ 📂 ui
┃ ┣ 📜 TeamGeneratorScreen.kt  # Основной экран с формированием команд
┃ ┣ 📜 TeamsResultScreen.kt    # Экран с результатами розыгрыша
┃ ┗ 📂 components
┃    ┣ 📜 PlayerItem.kt        # Карточка игрока в списке
┃    ┗ 📜 PlayerDialog.kt      # Диалог редактирования игрока
┗ 📜 MainActivity.kt           # Точка входа в приложение
```

## 🚀 Как запустить

1. Открой проект в **Android Studio Hedgehog+**
2. Убедись, что у тебя установлен **JDK 17+**
3. Выполни сборку проекта:
   ```bash
   ./gradlew assembleDebug
   ```

4. Запусти на эмуляторе или устройстве Android (API 24+)

---

## 🧠 Логика работы

* При добавлении игрока ему автоматически присваивается уникальный `UUID`
* Флажок напротив имени игрока указывает его **присутствие**
* При нажатии *Сформировать команды* приложение случайно делит отмеченных игроков пополам
* Результат отображается на отдельном экране с возможностью вернуться обратно
